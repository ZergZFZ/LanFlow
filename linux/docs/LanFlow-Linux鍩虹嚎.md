# LanFlow Linux 版功能/UI 基线（Windows 对照）

> 目标：以 Windows 原生版 v1.3.7（PRD 基线）为统一目标，分批对齐 Linux（Avalonia）版。
> 基线起点：linux 分支 @ `deb97e5`（round3.11，D1–D13 已结案，"能跑起来"达成）。
> 环境约束：UOS 20 Pro / glibc 2.28 / X11 / 无网络（U 盘拷贝测试）→ 每批以 Headless 探针自测 + 实机包 + 取证日志验收。
> 状态：活跃 ｜ 最近更新：2026-08-07
> 维护：随缺陷板同仓留痕（docs/）。

---

## 1. 目标与原则

1. **统一目标** = Windows 版 v1.3.7 已发布能力（Launcher-PRD §2）+ 设置 8 分类 + 设计 token 体系。
2. **分批对齐、功能优先**：先补"日常使用闭环"（加应用→整理→启动），再做交互、设置/UI、系统集成、性能。
3. **每批验收闭环**：构建 0 错误 → Headless 探针复验 → 实机包 + 取证日志（`[LanFlow]` 行 + Bounds dump）→ 更新缺陷板/基线。
4. **Linux 特有取舍单独决策**（§5），不作为差距硬对齐。

## 2. 现状基线（已达成，round3.11）

- 缺陷板 D1–D13 全部结案；`LanFlow-linux-x64-round3.11.tar.gz` 为当前有效包。
- 已具备：启动/托盘（显示隐藏/退出）/主题 10 色/搜索过滤/分组增删改切/项目增删启动（`.desktop` Exec 解析、可执行直启、命令 `bash -c`）/X11 全局热键（字母/数字键可靠）/开机自启（autostart）/配置原子写/Headless 探针。

## 5. Linux 特有取舍（决策记录）

| 项 | 决策 | 依据 |
|---|---|---|
| 更新机制（D4） | Linux 不做应用内更新，发布说明 + 手动解压替换文档化 | 无分发通道；UOS 离线环境 |
| SVG 图标 | D8 回退后暂缺；B5 或独立项恢复，需验证 glibc 2.28 兼容的替代方案 | 纯外观，不阻断功能 |
| import-manifest（A8） | B1 以"批量文件选择 + 目录导入"先行；manifest 契约后置，待有外部工具对接需求再定 | 避免为无人使用的契约投入 |
| 热键 | 推荐字母/数字 + 修饰键（Ctrl+Alt+Q / Ctrl+Alt+1）；符号键不承诺 | D13 结案结论 |
| 外观 | Deepin 原生装饰窗口；与 Windows 无边框+阴影不强行对齐 | X11 平台限制，已知差异 |
| 内存阈值 | ≤450MB（取证件启用期间） | 缺陷板 §3.6 |

## 6. 验收规范（沿用缺陷板）

1. 构建 0 错误；
2. 渲染/逻辑类修复先 Headless 探针复现/复验；
3. 实机取证：`[LanFlow]` 诊断行 + 关键控件 Bounds dump + 全局异常日志；
4. 内存 ≤ 450MB；
5. 每批一次实机回归通过后才进入下一批。
