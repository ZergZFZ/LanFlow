## 5. B5-2 虚拟化受限评估记录

- **结论**：不实施（记录留档）。
- **依据**：Avalonia 无开箱 VirtualizingWrapPanel；ItemsRepeater（experimental）与现有拖放/编辑按钮/空状态叠加改造风险高；启动器个人场景项目量通常 < 数百，WrapPanel 全量渲染可接受。
- **替代**：图标 LRU 有界化（B5-1）已收敛主要内存增长点；若实机大数据量滚动出现卡顿，再评估 ItemsRepeater + UniformGridLayout。
