# 快捷键截图功能 · 第一批详细设计（框选 + 自动复制）

> 状态：活跃 ｜ 最近更新：2026-08-11
> 适用分支：`windows`（WPF 版，当前版本 1.3.8 → 发布目标 v1.4.8 系列）
> 关联文档：docs/ARCHITECTURE.md、docs/DEVELOPMENT-ROADMAP.md

## 1. 范围与目标

**第一批**：自定义快捷键 → 全屏冻结 → 框选 → 松开自动复制到剪贴板 → 退出。
第二批（另行设计）：选区边缘弹出编辑快捷条（箭头 / 框选 / 颜色 / 马赛克 / 另存为）。

| 项 | 内容 |
|---|---|
| 入口 | 新增全局热键「截图」（设置页可自定义，默认 `Ctrl+Shift+A`） |
| 流程 | 热键 → 多屏截图（冻结画面）→ 全屏遮罩拖拽框选 → 松开即自动复制选区到剪贴板 |
| 退出 | 松开鼠标自动复制并关闭；`Esc` 取消；防重入 |
| 不在本批 | 编辑快捷条、标注、另存为、选区二次调整 |

## 2. 架构总览

设置页(截图快捷键) ──> ConfigStore(Settings.ScreenshotHotkey) ──> MainWindow 注册

## 4. 详细设计

### 4.1 HotkeyService 多热键扩展（最小改动）

现状：`HotkeyId` 为 `const int = 1` 单槽。截图需要第二个全局热键，同一窗口句柄用相同 id 二次注册会失败，因此：

- 构造参数：`public HotkeyService(int hotkeyId = 1)`，字段 `_hotkeyId` 替代常量；
- `Register`/`TryRegister`/`Dispose`/`WindowProcedure` 中的 id 判断全部改用 `_hotkeyId`；
- MainWindow 持有两个实例：`_hotkeyService = new HotkeyService(1)`（主窗热键）、`_screenshotHotkeyService = new HotkeyService(2)`（截图热键）；
- 同一 `HwndSource` 上两个 hook 各自过滤自己的 `wParam`，互不干扰。

### 4.2 Settings 数据模型

```csharp
[JsonPropertyName("screenshotHotkey")]
public string ScreenshotHotkey { get; set; } = "Ctrl+Shift+A";
```

- `Clone()` 中同步复制；
- `ConfigStore.Load`：`ScreenshotHotkey` 为空或非法时回写默认值（对齐现有 `Hotkey` 的兜底逻辑）；
- 兼容：旧配置文件无此字段 → 自动取默认值，不迁移。

### 4.3 ScreenshotService（多屏截图 + 裁剪 + 复制）

| 方法 | 说明 |
|---|---|
| `CaptureAllScreens()` | 取 `SystemParameters.VirtualScreen`（可含负坐标），逐屏 `Graphics.CopyFromScreen` 抓取后拼成一张 `BitmapSource` 返回（含整图矩形） |
| `CopySelection(BitmapSource full, Int32Rect rect)` | 用 `CroppedBitmap` 裁剪选区 → `Clipboard.SetImage` |
| `DpiFactor` | `VisualTreeHelper.GetDpi` / `PresentationSource` 取缩放比，窗口 DIP 坐标 → 物理像素换算的公用系数 |

**DPI 关键约定**：`CopyFromScreen` 按物理像素抓屏；`ScreenshotCropWindow` 在 `VirtualScreen` 全屏时其 DIP 坐标与物理像素存在缩放差。设计统一用「物理像素」为截图坐标系：
- 抓屏 bitmap 直接按物理像素；
- 框选窗口 `Left/Top/Width/Height` 用虚拟屏幕的物理像素值（窗口在 100% 缩放时 DIP==像素；缩放 >100% 时窗口尺寸用 DIP 会被系统放大，需在窗口内用 `VisualTreeHelper.GetDpi` 反算）——**首版以「100% 缩放下像素对齐为硬验收」，缩放 >100% 按同系数换算实现并实机验证**。

### 4.4 ScreenshotCropWindow（全屏遮罩框选）

窗口属性：

```
WindowStyle=None  AllowsTransparency=True  Background=Transparent
Topmost=True  ShowInTaskbar=False  WindowStartupLocation=Manual
Left/Top = VirtualScreen.Left/Top（负坐标直接支持）
Width/Height = VirtualScreen.Width/Height（单窗口覆盖所有屏）
```

界面结构：

```
Grid
├── Image（冻结截图，Stretch=None，Align 虚拟屏左上角，作为截图背景）
├── Canvas（叠加层）
│   ├── 选区矩形（半透明遮罩 + 1px 边框 + 对角尺寸文本）
│   └── 顶部提示条（"拖动选择截图区域　Enter 确认　Esc 取消"）
└── （可选）半透明蒙版：选区外压暗（用 Rectangle 四块拼合）
```

交互：

| 事件 | 行为 |
|---|---|
| `MouseLeftButtonDown` | 记录起点，进入绘制态 |
| `MouseMove` | 实时更新选区矩形（坐标夹在图像区内） |
| `MouseLeftButtonUp` | 选区有效（≥ 4×4 px）→ **立即裁剪 + 复制 + 关闭**；过小视为无效提示 |
| `Esc` | 取消，关闭，不复制 |
| `Key.Enter` | 同确认（复制并关闭），首版可选 |

防重入：MainWindow 侧以「截图窗口是否已打开」为开关，重复触发直接忽略。

### 4.5 主窗口接线（MainWindow）

```csharp
private readonly HotkeyService _screenshotHotkeyService = new(hotkeyId: 2);
private ScreenshotCropWindow? _cropWindow;

private void RegisterScreenshotHotkey()
{
    if (!_screenshotHotkeyService.Register(this, ShowScreenshotCrop, _viewModel.Settings.ScreenshotHotkey))
        // 状态栏提示："截图快捷键 Ctrl+Shift+A 注册失败（可能被占用）"
}

private void ShowScreenshotCrop()
{
    if (_cropWindow != null) return;              // 防重入
    var full = ScreenshotService.CaptureAllScreens();
    if (full is null) return;
    if (IsVisible) Hide();                         // 截图前隐藏自身，避免入镜（截图后恢复）
    _cropWindow = new ScreenshotCropWindow(full, ScreenshotService.DpiFactor);
    _cropWindow.Closed += (_, _) => { _cropWindow = null; if (!IsVisible) Show(); };
    _cropWindow.Show();
}
```

- 启动时注册；设置保存成功后重新 `TryRegister` 新组合（失败回退旧值并提示）。

### 4.6 设置页集成

- 在 `SettingsWindow.xaml` StartupPanel「快捷键」区块（全局快捷键下方）新增一行：「截图快捷键」+ `ScreenshotHotkeyBox`（`IsReadOnly`、`KeyDown` 归一化，复用 `HotkeyService.TryNormalize`）；
- 加载：`ScreenshotHotkeyBox.Text = Working.ScreenshotHotkey`；
- 保存：`Update(settings => settings.ScreenshotHotkey = normalized)`；
- 冲突检测：与「全局快捷键」值相同 → 阻止保存并提示；
- 保存成功 → 通知 MainWindow 重新注册截图热键（通过现有设置保存回调链路）。

## 5. 状态机

```
Idle ──热键──▶ Capturing(多屏截图) ──▶ Selecting(拖拽) ──MouseUp──▶ Copied(复制) ──▶ Closed ──▶ Idle
                                              │
                                              └─Esc / 无效选区──▶ Closed ──▶ Idle
```

## 6. 验收标准（第一批）

| # | 验收点 | 验证方式 |
|---|---|---|
| 1 | 设置页可自定义截图快捷键，保存后立即生效、重启后保留 | 改键 → 触发 → 重启 → 再触发 |
| 2 | 与全局快捷键冲突时阻止保存并提示 | 设相同组合 → 观察 |
| 3 | 热键触发后屏幕冻结、全屏遮罩、可拖拽框选 | 触发 → 拖拽 |
| 4 | 松开鼠标自动复制选区到剪贴板 | 粘贴到画图/WPS 验证内容与选区一致 |
| 5 | Esc 取消不复制 | 触发 → Esc → 剪贴板不变 |
| 6 | 防重入：连按热键只弹一个框选窗口 | 连按两次热键 |
| 7 | 主窗口可见时触发截图，画面不含 LanFlow 自身 | 显示主窗 → 触发 → 检查 |
| 8 | 多屏 + 125% 缩放下选区与截图内容对齐 | 实机双屏 + 缩放验证 |

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 多屏 + DPI 缩放坐标偏差 | 选区与内容错位 | 统一物理像素坐标系；100% 缩放硬验收，>100% 实机验证 |
| 热键被占用/与系统冲突 | 注册失败 | 状态栏提示 + 保持旧值 |
| 透明全屏窗口性能 | 拖拽卡顿 | 截图用静态 Image，选区仅重绘 Canvas 四个矩形，避免整窗重绘 |
| AllowsTransparency 边界绘制 | 选区边缘模糊 | 蒙版用四块 Rectangle 拼合，选区框用 1px 对齐像素的 Rectangle |
