# R4 性能基线记录（2026-08-21 · v1.5.2）

> 对应 `Launcher-PRD.md` P3 与 `DEVELOPMENT-ROADMAP.md` R4：轻量性与启动性能。
> 原则：性能结论来自目标机器实测，不以主观感受替代证据；本文件是第一份可复现基线，
> 后续优化（图标缓存、启动路径、full/lite 体积）以此为回归参照。

## 1. 环境与被测物

| 项 | 值 |
|---|---|
| 被测版本 | v1.5.2（`artifacts/1.5.2/full/LanFlow.exe`，即 GitHub Release 同一二进制） |
| 测量工具 | `tools/perf-baseline.ps1`（Process + UIAutomation 采样，脚本随仓库分发可复跑） |
| 操作系统 | Windows 10 企业版 LTSC 10.0.19044 |
| CPU | Intel Core i7-4790 @ 3.60GHz（4C/8T） |
| 内存 | 15.9GB |
| 配置 | 本机真实 `%AppData%\LanFlow\config.json`（非空工作区） |

## 2. 测量方法

1. 停止全部 LanFlow 实例 → 启动被测 exe → 以 10ms 轮询等待主窗口句柄就绪，计为冷启动耗时；
2. 就绪时刻与空闲 5s 后分别采样工作集（WS）与私有提交内存（Private Bytes）；
3. 通过 UIAutomation 对分组标签执行 SelectionItemPattern.Select() 连续切换，
   每次切换后 300ms 采样峰值、900ms（越过 v1.5.2 的 800ms 防抖）后让回收发生；
   最后一次切换 3s 后采样"回收后"值；
4. 每组测量重复 3 次（每次均为冷启动），取中位数。

## 3. 结果（3 次冷启动，2026-08-21）

| 指标 | Run 1 | Run 2 | Run 3 | 中位 |
|---|---|---|---|---|
| 冷启动 → 主窗口就绪 (ms) | 982 | 960 | 972 | **≈972** |
| 就绪时工作集 (MB) | 121.1 | 120.1 | 120.1 | **120.1** |
| 就绪时私有内存 (MB) | 59.7 | 57.6 | 57.4 | **57.6** |
| 空闲 5s 工作集 (MB) | 130.8 | 130.7 | 130.7 | **130.7** |
| 空闲 5s 私有内存 (MB) | 67.9 | 68.0 | 67.7 | **67.9** |
| 分组切换峰值 工作集/私有 (MB) | 153.3 / 81.0 | 153.3 / 81.2 | 153.1 / 80.9 | **153.2 / 81.0** |
| 回收后 工作集/私有 (MB) | 153.5 / 81.0 | 153.5 / 81.2 | 153.3 / 80.9 | **≈峰值** |
| 发布体积 full.zip / lite.exe | — | — | — | **64.4 / 2.3 MB** |

## 4. 解读

1. **冷启动 ≈ 0.97s**（含 .NET 运行时初始化 + 配置读取 + 首帧）。对常驻托盘应用属可接受起点；
   R4 后续若做 XAML 预编译/延迟图标加载，以此值为对照。
2. **稳态驻留 ≈ 131MB WS / 68MB 私有**。WS 中约 50MB 为共享 DLL 映射，真实占用看私有字节。
3. **分组切换不累积垃圾**：切换峰值与回收后完全一致（私有稳定在 81MB），说明
   v1.5.2 的防抖 GC+修剪在"仅切分组"场景下无可观测收益——切换后的内存是**活对象**
   （图标缓存与虚拟化面板持有），不是垃圾。该结论符合预期：修剪主要收益场景是
   截图关闭等大位图释放路径（见 CHANGELOG 1.5.2 第二条），而非分组切换。
   —— 这正是要先测基线的价值：避免对无收益路径做无效优化。
4. **热键呼出延迟未取得自动化数据**：SendKeys 合成按键与 UIA IsOffscreen 组合在本机不可靠
   （三次均为 null）。该项列入手工回归协议：秒表/录屏测量热键按下到窗口可见的间隔，
   目标阈值建议 ≤ 150ms（首帧已预热场景）。

## 5. 建议的回归阈值（供后续版本对照）

| 指标 | 基线中位 | 建议告警阈值 |
|---|---|---|
| 冷启动耗时 | 972ms | > 1500ms |
| 空闲私有内存 | 67.9MB | > 100MB |
| 切换后私有内存（不回落即正常） | 81.0MB | 持续增长 > 20% 需查泄漏 |
| full.zip 体积 | 64.4MB | > 75MB |
| lite.exe 体积 | 2.3MB | > 3MB |

## 6. 复跑方式

```powershell
powershell -ExecutionPolicy Bypass -File tools\perf-baseline.ps1 `
    -ExePath <LanFlow.exe 路径> -Runs 3
```

注意：脚本会停止正在运行的 LanFlow 实例（单实例互斥体冲突）；结束后不会自动重启。
